# Contact Manager App 📱

این یک اپلیکیشن تحت وب برای مدیریت مخاطبین است که با استفاده از **React** توسعه یافته است. هدف اصلی این پروژه، پیاده‌سازی یک سیستم مدیریت State اصولی و مقیاس‌پذیر بدون استفاده از کتابخانه‌های جانبی پیچیده مانند Redux است.

## 🌟 ویژگی‌های پروژه

* **مدیریت State پیشرفته:** استفاده از ترکیب `Context API` و `useReducer` برای مدیریت متمرکز داده‌ها.
* **عملیات CRUD:** قابلیت افزودن مخاطب جدید، ویرایش اطلاعات موجود و حذف مخاطبین.
* **حذف گروهی (Bulk Delete):** امکان انتخاب چندین مخاطب از طریق چک‌باکس و حذف آن‌ها به صورت یکجا.
* **جستجوی آنی (Live Search):** فیلتر کردن لیست مخاطبین بلافاصله پس از تایپ در نوار جستجو.
* **مدیریت حرفه‌ای فرم:** استفاده از `React Hook Form` برای مدیریت فرم، کنترل ورودی‌ها و مدیریت خطاها.
* **اعتبارسنجی فرم:** استفاده از `Yup` و `yupResolver` برای پیاده‌سازی Validation ساختاریافته و قابل نگهداری.
* **معماری ماژولار:** استفاده از `CSS Modules` برای جلوگیری از تداخل استایل‌ها.
* **تولید هوشمند ID:** استفاده از کتابخانه `uuid` جهت اطمینان از یکتایی شناسه مخاطبین.

## 🛠 تکنولوژی‌های استفاده شده

این پروژه با ابزارهای زیر ساخته شده است:

* **React.js**

  * `useState`
  * `useReducer`
  * `useContext`
* **JavaScript (ES6+)**
* **CSS Modules**
* **Context API**
* **React Hook Form** — مدیریت و کنترل فرم
* **Yup** — اعتبارسنجی فرم
* **@hookform/resolvers** — اتصال Yup به React Hook Form
* **uuid** — تولید ID یکتا برای مخاطبین

## 🚀 نحوه اجرا

برای اجرای این پروژه روی سیستم خود، مراحل زیر را دنبال کنید:

### 1. کلون کردن مخزن (Repository)

ابتدا مخزن پروژه را با دستور زیر کلون کنید:

```bash
git clone <YOUR_REPOSITORY_URL>
```

### 2. ورود به پوشه پروژه

پس از کلون شدن مخزن، وارد پوشه پروژه شوید:

```bash
cd contact-manager-app
```

### 3. نصب کتابخانه‌ها

برای نصب تمام وابستگی‌ها و کتابخانه‌های موردنیاز پروژه، دستور زیر را اجرا کنید:

```bash
npm install
```

وابستگی‌های اصلی مورد استفاده در پروژه:

```bash
npm install react-hook-form yup @hookform/resolvers uuid
```

### 4. اجرای پروژه

در نهایت، برای اجرای پروژه از دستور زیر استفاده کنید:

```bash
npm start
```

پس از اجرای موفقیت‌آمیز، پروژه روی محیط توسعه اجرا خواهد شد.


## 📝 Form Validation

اعتبارسنجی اطلاعات مخاطب با استفاده از **Yup** انجام می‌شود و `React Hook Form` وظیفه مدیریت فرم و خطاهای مربوط به ورودی‌ها را بر عهده دارد.

قوانین اعتبارسنجی شامل موارد زیر است:

* نام الزامی است.
* نام خانوادگی الزامی است.
* ایمیل الزامی بوده و باید فرمت معتبر داشته باشد.
* شماره تلفن الزامی بوده و باید دقیقاً ۱۱ رقم باشد.

منطق Validation از کامپوننت اصلی جدا شده و در فایل اختصاصی `contactSchema.js` قرار گرفته است.
